**Effective date:** 7 November 2026  
**Status:** Phase 1 preview draft

2. **Credentials.** Each API key is paired with a private Authorised Verification Token. Keep both confidential, store them server-side, rotate them after suspected exposure, and revoke unused credentials. You are responsible for activity performed using your credentials.
3. **Sandbox data.** Sandbox fixtures are synthetic examples for software testing only. They do not represent actual airports, aircraft, weather, traffic or operational conditions. Sandbox output must never be used for navigation, dispatch, air traffic control, flight planning or real-world safety decisions.
4. **Live and third-party data.** Live API availability depends on external data providers, licensing, network conditions and source permissions. Phase 1 does not promise live aircraft, ATIS, METAR or TAF availability. You must comply with all applicable provider terms and attribution requirements.
5. **No operational guarantee.** VEYRO API is a developer service, not an approved aeronautical information publication, certified navigation system, dispatch release or air traffic control tool. Data may be incomplete, delayed, inaccurate or unavailable. Always verify operational information against authoritative sources.
6. **Quotas and availability.** Requests are subject to per-key quotas, rate limits, maintenance and fair-use controls. We may suspend credentials that threaten service reliability or violate these terms. Phase 1 is a preview and may change without notice.
7. **Privacy and logging.** We store account details, credential hashes and request metadata such as endpoint, method, response code and timestamp for security and usage analytics. Raw API keys and verification tokens are not stored in readable form. Avoid placing personal or sensitive information in request paths or query parameters.
8. **Payments.** No paid subscription is activated in Phase 1. Future paid plans will be governed by plan-specific pricing, billing and cancellation terms presented before purchase.
